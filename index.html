왜 필요한가요

채팅은 한 줄로 쌓이는데, 일은 가지를 치며 진행돼요.

한참 이야기하다 곁길로 새고, 돌아와서 정하고, 같은 파일이 몇 번씩 바뀌어요. 스크롤만으로는 어디서 무엇을 정했는지, 무엇을 빠뜨렸는지 다시 찾기 어려워요.

채팅으로 보면

  • 환율 알림 봇을 만들고 싶어
  • 폴링이랑 웹훅은 뭐가 달라?
  • 그럼 폴링으로 하자
  • 목표가랑 비교해서 알림 보내 줘
  • 임계값만 1,380원으로 바꿔 줘

위에서 아래로 한 줄. 정한 순간도 곁길도 같은 모양이에요.

가닥이 하는 일

읽고, 정리하고, 놓친 일을 먼저 알려 줘요.

가닥은 대화 옆에 붙어 있어요. 대답은 하지 않고, 흐름을 그려요.

질문 하나가 역 하나예요. 정한 순간은 큰 점과 굵은 이름으로, 곁길로 샌 이야기는 아래로 갈라지는 회색 선으로, 지금 있는 곳은 빨간 점으로 보여요. 역을 누르면 그때의 대화로 가요.

요청하지 않았는데 바뀐 파일, 답이 오지 않은 요청, 새 대화로 옮길 때 챙길 맥락을 찾아요. 가닥이 기록을 다시 읽어 근거를 직접 본 것만 할 일로 올리고, 어떻게 판단했는지 기록을 남겨요.

프로젝트마다 색이 다른 노선으로, 최근 7 · 15 · 30일의 대화가 한 장에 놓여요. 이어서 한 대화는 환승으로 이어지고, 노선을 누르면 그 대화의 한 줄 노선도로 들어가요.

Mac에서는 화면 가장자리에 가닥 버튼이 떠 있어요. 누르면 지금 대화의 노선도가 일하던 앱 위에 뜨고, 둘레 버튼으로 할 일 · 정한 것 · 산출물을 바로 열어요. 버튼은 내가 고쳐 둘 수 있어요.

‘앞길 보기’를 누르면 하려는 일을 읽고, 지난 기록과 작업 폴더의 문서에서 갈 수 있는 길을 찾아 셋까지 내밀어요. 답이 아니라 LLM에게 가져갈 물음이에요. 찾아본 것이 없는 길은 내지 않아요.

안전과 통제

대화는 내 PC에, 보내는 일은 내 손에.

대화는 내 PC에 저장돼요

읽은 대화는 이 컴퓨터의 .gadak 폴더에만 있어요. 정리할 때만 그 턴의 일부(질문 앞부분, 답의 앞뒤, 바뀐 파일의 이름과 줄 수)가 내가 연결한 AI로 가요. API 키는 macOS 키체인이나 Windows 자격 증명 관리자에만 둬요.

가닥은 대답하지 않아요

가닥 화면에는 채팅 입력창이 없어요. 할 말을 만들어 건네기까지만 하고, 보내는 것은 내가 해요. 내가 켠 두 종류(요청 외 변경 되돌리기 · 이어 가기 요약)만 가닥이 직접 보내요.

자주 묻는 것

받기 전에 궁금한 것

무료인가요?

네. 가닥은 수업 과제로 만든 무료 앱이고 코드는 GitHub에 공개돼 있어요. 정리에 쓰는 AI는 내가 이미 쓰는 구독이나 API 키를 연결해요. 가닥이 정리에 쓴 만큼은 그 구독의 한도나 키의 요금에 들어가요.

어떤 대화를 읽나요?

Claude Code와 Codex의 대화는 켜 두면 알아서 읽어요. 크롬에서 연 Claude · ChatGPT 웹 대화는 크롬 확장을 넣으면 읽고, 지난 대화는 내보내기 파일로 한꺼번에 넣을 수 있어요. Cursor는 Mac에서 한 번 연결해요. ChatGPT 웹, Cursor, 내보내기 파일은 아직 실제 환경에서 끝까지 확인하지 못했어요. 데스크톱 앱과 모바일 앱의 채팅은 직접 읽지 못해요.

내 대화가 어디로 가나요?

대화 원문은 내 PC에만 저장돼요. 정리할 때 그 턴의 질문 앞부분과 답의 앞뒤 일부, 바뀐 파일의 이름과 줄 수가 내가 연결한 AI의 회사로 가요. 놓친 일을 확인하는 턴에서는 조금 더 읽어 보내요. 여기서 받는 앱은 사용 기록을 가닥 팀에 보내지 않아요.

어떤 AI가 있어야 하나요?

Claude 구독(Pro · Max), ChatGPT 구독(Plus · Pro), LLM API 키(Anthropic · OpenAI · Gemini) 가운데 하나예요. 가닥 창의 ‘AI 연결’에서 골라요. 연결하지 않으면 대화를 읽어 보여 주기만 해요.

처음 열 때 경고가 떠요

가닥은 과제로 만든 앱이라 Apple과 Microsoft의 유료 서명이 없어요. 그래서 처음 한 번 확인이 필요해요. Mac은 시스템 설정 → 개인정보 보호 및 보안 → ‘그래도 열기’, Windows는 ‘추가 정보’ → ‘실행’이에요. 받은 파일이 맞는지는 받기 페이지의 확인 값(SHA-256)으로 볼 수 있어요.

Windows에서는 무엇이 다른가요?

Windows 판은 처음 나온 판이에요. 만든 사람들에게 Windows PC가 없어서 Mac에서 Wine으로만 확인했고, 진짜 PC에서는 아직 켜 보지 못했어요. 떠 있는 가닥 버튼, Claude Code · Codex를 대신 받아 주는 ‘연결하기’, Cursor 연결과 자동 실행, Claude 사용 한도 게이지는 아직 없어요.

가닥의 정리를 얼마나 믿어도 되나요?

정리는 AI가 하는 일이라 틀릴 수 있어요. 재 본 대화에서 곁길은 열에 예닐곱을 찾았고, ‘정함’ 표시는 아직 흔들려요. 그래서 할 일은 가닥이 근거를 직접 확인한 것만 올리고, 무엇을 보고 그렇게 판단했는지 기록을 남겨요.

지우려면 어떻게 하나요?

Mac은 응용 프로그램 폴더의 가닥을 휴지통에 넣고, Windows는 설정 → 앱에서 가닥을 제거해요. 읽어 둔 대화까지 지우려면 홈 폴더의 .gadak 폴더도 지워요.
