First launch on a Mac

  1. Open the disk image (.dmg) and drag Gadak (가닥) onto the Applications folder beside it.
  2. Open Gadak from Applications. The first time, macOS blocks it as coming from an unidentified developer. Click Done to close the notice.
  3. Go to System Settings → Privacy & Security and click Open Anyway near the bottom. On macOS 14 or earlier, right-click Gadak → Open → Open also works.
  4. When Gadak starts, choose an AI in the AI 연결 (Connect AI) window. From then on it opens normally.

Move it to Applications before you launch it. Run straight from the disk image, the Cursor and Claude Code connections will not work.

First launch on Windows

  1. Open the installer (.exe). If a blue Windows protected your PC window appears, click More info → Run anyway.
  2. Next → Install. It installs for your account only, so no administrator password is needed. Python is included.
  3. Start 가닥 (Gadak) from the Start menu or the desktop. It opens in an Edge or Chrome window without an address bar. Closing that window quits Gadak.
  4. Choose an AI under AI 연결 (Connect AI) at the bottom left. If Claude Code or Codex is already installed it is used as is; otherwise paste an LLM API key.

Chrome extensionReads Claude and ChatGPT on the web

With the extension added, conversations you open on claude.ai and chatgpt.com in Chrome are read and sent only to the Gadak on your own computer. It is not on the Web Store, so you add it in developer mode.

Download the extension zip
  1. Unzip the download. If Gadak is already installed you can skip this: 찾은 곳 → 폴더 경로 복사 (Sources → Copy folder path) in the Gadak window gives you the copy inside the app.
  2. Enter chrome://extensions in Chrome's address bar and turn on Developer mode at the top right.
  3. Click Load unpacked and choose the unzipped folder (gadak-extension).
  4. Reload any Claude or ChatGPT tabs that were already open. With Gadak running, a conversation you open shows up in its list.

Reading Claude on the web has been confirmed. ChatGPT on the web has not been confirmed yet. Temporary chats and incognito windows are never read.

Removing Gadak

On a Mac, move Gadak from Applications to the Trash. On Windows, uninstall it under Settings → Apps. To delete the conversations it read as well, remove the .gadak folder in your home folder.
