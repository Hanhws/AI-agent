가닥도움말

처음 3분

가닥은 AI와 나눈 대화를 지하철 노선도로 그려 주고, 놓친 일을 먼저 알려 줘요. 가닥은 대답하지 않아요. 대화는 쓰던 곳에서 그대로 해요.

  1. 가닥을 켜요. 이 MacPC의 Claude Code · Codex 대화를 알아서 읽어요.
  2. 정리할 AI를 연결해요. 왼쪽 아래 AI 연결에서 하나를 골라요.
  3. 왼쪽에서 대화를 골라요. 위에 노선도, 가운데에 대화, 오른쪽에 목록이 나와요.
  4. 노선도의 역을 눌러요. 그 이야기를 한 자리로 바로 가요.
대화 글은 이 MacPC에만 저장돼요. 정리할 때만 내가 연결한 AI로 가요.

AI 연결

가닥이 대화를 정리할 때 쓰는 AI예요. 왼쪽 아래 AI 연결에서 셋 중 하나를 골라요. 연결하지 않으면 대화를 읽어 보여 주기만 해요.

Claude 구독
Pro · Max 구독으로 써요. 추가 요금이 없어요. 연결하기를 누르면 브라우저에서 로그인해요.
ChatGPT 구독
Plus · Pro 구독으로 써요. 추가 요금이 없어요. 연결하기를 누르면 브라우저에서 로그인해요.
LLM API 키
Anthropic · OpenAI · Gemini의 API 키를 붙여 넣어요. 쓴 만큼 그 키로 요금이 나가요. 키는 이 Mac의 키체인이 PC의 Windows 자격 증명 관리자에만 둬요.
Gemini 무료 키
Google AI Studio의 무료 키로도 정리해요. 요금이 없는 대신 한도가 낮고, 보낸 글이 Google의 제품 개선에 쓰일 수 있어요.
사용 한도
구독으로 연결하면 내가 쓰는 Claude · ChatGPT와 같은 한도를 나눠 써요.

대화 읽어 오기

어디에서 한 대화를 읽는지는 왼쪽 아래 찾은 곳에 나와요.

Claude Code · Codex
할 일이 없어요. 켜면 알아서 읽어요.
Cursor
찾은 곳에서 연결을 한 번 눌러요.
Claude · ChatGPT 웹
크롬에 가닥 확장을 한 번 넣어요. 넣는 법은 찾은 곳에 있어요.
지난 대화 한꺼번에
각 서비스에서 내보낸 파일을 찾은 곳의 파일 고르기로 넣어요.
목록에서 빼기
대화에 마우스를 올리고 ×를 눌러요. 글은 지워지지 않고, 목록 맨 아래에서 되돌려요.

노선도 읽기

대화 한 개가 노선 한 줄이에요. 왼쪽이 처음, 오른쪽이 지금이에요. 위의 노선도 카드는 Esc로 접고 펴요.

본선
프로젝트 색의 굵은 선. 전체 지도에서도 같은 색이에요.
역
작은 검은 점. 한 번 묻고 한 번 답한 것. 누르면 그 자리로 가요.
정함
큰 검은 점과 굵은 역 이름. 그 자리에서 무언가를 정했어요.
지금
빨간 점과 둘레의 빛. 대화가 와 있는 자리예요.
곁길
아래로 45° 내려가는 회색 선. 하던 이야기에서 잠깐 벗어난 질문이에요.
할 일
역 아래의 빨간 고리. 아직 안 한 일이 있어요. 올리면 내용이 보여요.
끝낸 할 일
회색 고리. 끝낸 일이에요.
산출물
작은 점과 파일 이름. 그 자리에서 파일이 나오거나 바뀌었어요.
구간
노선 위의 이름표. 이야기의 단계예요.
접힌 구간
지난 구간은 눈금으로 줄어요. 이름표를 누르면 펴져요.
숨은 가지
역 위의 점선 곡선. 질문을 고쳐 다시 물은 흔적이에요.
대화 사이
회색 점선. ‘프로젝트 전체’로 볼 때 대화와 대화 사이를 이어요.
환승하기
노선 끝의 검은 화살표. 이 대화의 요약을 복사해요. 새 대화 첫머리에 붙여 넣어요.
전체 지도
맨 위 검은 띠의 버튼. 최근 30일의 모든 프로젝트와 대화를 한 장에 그려요. 포스터로 보기로 바꿔 볼 수 있고, Esc로 닫아요.
낮 · 밤
맨 위 검은 띠 오른쪽의 스위치(전체 지도에도 있어요). 밝은 화면과 어두운 화면을 바꿔요. 고른 것은 이 MacPC에 남아요.

할 일과 목록

오른쪽에 네 칸이 있어요. 위의 찾기 칸에 낱말을 치면 지난 대화까지 찾아요.

할 일
가닥이 찾은 놓친 일과 제안. 버튼을 누르면 AI에게 보낼 글이 복사돼요. 미루려면 나중에.
정한 것
지금까지 정한 것을 최근 순서로. 누르면 정한 자리로 가요.
산출물
대화에서 나온 파일. 여러 번 고친 파일은 판(v1 · v2)으로 묶여요.
앞길
여기서 갈 수 있는 길을 가닥이 미리 찾아본 것이에요.

할 일에 올라오는 것

빠진 요청
부탁했는데 답에서 빠진 것.
요청 외 변경
부탁하지 않았는데 AI가 바꾼 것.
끝나지 않은 곁길
곁길에서 정한 것 없이 돌아온 것.
이어 가기
새 대화를 열었을 때, 앞 대화에서 정한 것을 붙여 넣기.
반복 질문
다른 대화에서도 물었던 것. 그때 답을 다시 볼 수 있어요.
주제 전환
한 대화에 주제가 여럿 쌓였을 때, 새 대화로 옮기기를 권해요.
다음 할 일
앞길 살피기가 찾은 길.

가닥이 알아서 보내는 것

‘할 일’ 칸 아래에서 켜요. 요청 외 변경 되돌리기와 이어 가기 요약 두 가지만, 켰을 때만 가닥이 직접 보내요. 그 밖에는 글만 만들어 줘요.

앞길

가닥이 이 대화가 어디로 가려는지 읽고, 갈 수 있는 길을 셋까지 찾아 줘요. 답이 아니라 AI에게 물어볼 거리예요.

앞길 보기
‘앞길’ 칸 맨 위의 버튼. 누른 그 자리에서 한 번 살펴요. 30초에서 2분쯤 걸려요.
저절로 살피기
‘할 일’ 칸 아래에서 켜요. 무언가를 정했을 때 · 구간이 바뀔 때 저절로 살펴요.
이어 가기
하던 방향으로 다음에 할 만한 일.
다른 길
지금 방법 말고 해 볼 수 있는 방법.
미리 챙길 것
이대로 가면 걸릴 수 있어 먼저 확인할 것.
이 길 보기
왜 그 길인지, 무엇을 찾아봤는지 보여요. 이 길로 묻기를 누르면 보낼 글이 복사돼요.
살필 때마다 AI 사용 한도를 조금 써요(Claude Pro의 5시간 한도로 한 번에 0.7%쯤). 그래서 저절로 살피기는 꺼 둔 채로 시작해요.

떠 있는 버튼

Mac 앱에서 화면 가장자리에 걸쳐 있는 가닥 버튼이에요. Windows에 깐 가닥에는 아직 없어요. 다른 앱을 쓰는 동안에도 보여요. 마우스를 올리면 둘레에 버튼이 펴져요.

노선도
지금 쓰는 대화의 노선도를 화면 위쪽에 띄워요. 한 번 더 누르면 닫혀요.
할 일 · 정함 · 산출물
그 칸을 연 목록 창을 따로 띄워요.
찾기 · 창
가닥 창을 열어요. ‘찾기’는 대화 찾기 칸으로 바로 가요.
버튼 바꾸기
가닥 버튼을 오른쪽 클릭 → 버튼 편집. 버튼을 빼거나 더하고, 차례를 바꿔요. 여섯 개까지 둬요.
프로젝트 버튼
버튼 편집에서 프로젝트를 더하면, 그 버튼이 그 프로젝트의 노선도를 띄워요. 가닥 창을 열지 않고 프로젝트를 바꿔 봐요.
옮기기
가닥 버튼을 끌면 다른 가장자리로 옮겨져요.
닫기
떠 있는 창은 Esc로 닫아요.
숨기기 · 다시 켜기
가닥 버튼을 오른쪽 클릭 → 버튼 숨기기. 다시 켜려면 가닥 창 맨 위 오른쪽의 가닥 토글 스위치, ⇧⌘B, 메뉴 보기 → 떠 있는 버튼, 또는 Dock의 가닥 아이콘을 오른쪽 클릭 → 떠 있는 버튼 보이기.

역

구간

정리 엔진

판단 기록
가닥이 할 일을 찾을 때 무엇을 보고 판단했는지 적은 기록.

막힐 때

먼저 왼쪽 아래의 한 줄을 봐 주세요. 가닥이 지금 무엇을 하는지, 왜 멈췄는지가 거기에 나와요.

역 이름이 질문 첫머리 그대로예요

정리할 AI가 연결되지 않았어요. 왼쪽 아래 AI 연결에서 하나를 골라요.

빨간 글씨로 멈췄다고 나와요

사용 한도에 걸렸거나 로그인이 풀렸어요. 한도가 풀린 뒤 정리 다시를 누르면 멈춘 데서 이어 가요.

앞길 보기를 눌렀는데 아무것도 안 나와요

버튼 아래 한 줄을 봐 주세요. “살피는 중”이면 기다리면 돼요. “내밀 만한 길을 찾지 못했어요”는 근거 있는 길이 없었다는 뜻이에요. “살피지 못했어요” 뒤에는 까닭이 적혀 있어요.

대화가 하나도 안 보여요

찾은 곳에서 무엇을 찾았는지 봐 주세요. 이 MacPC에서 AI를 쓴 적이 없으면 읽을 기록이 없어요.

필요 없는 대화가 섞여 보여요

그 대화에 마우스를 올리고 ×를 눌러요. 목록 맨 아래 “뺀 대화”에서 되돌려요.

웹에서 한 대화가 안 들어와요

크롬의 가닥 확장 아이콘을 눌러 봐요. 가닥이 꺼져 있으면 켜고, 확장을 넣기 전에 열어 둔 탭은 새로고침해요.

떠 있는 버튼이 안 보여요

숨겨 둔 거예요. 가닥 창 맨 위 오른쪽의 가닥 토글 스위치를 켜거나, Dock의 가닥 아이콘을 오른쪽 클릭 → 떠 있는 버튼 보이기. 켰는데도 없으면 화면의 네 가장자리를 둘러봐요.

화면이 너무 밝거나 어두워요

맨 위 검은 띠 오른쪽의 낮 · 밤 스위치로 바꿔요. 고르지 않으면 MacWindows의 화면 모드를 따라가요.

처음 열 때 Mac이 막아요

시스템 설정 → 개인정보 보호 및 보안 → 아래쪽의 그래도 열기를 눌러요. 한 번만 하면 돼요.

설치할 때 Windows가 막아요

“Windows의 PC 보호” 창에서 추가 정보 → 실행을 눌러요.

찾는 말이 든 설명이 없어요. 다른 낱말로 찾아봐 주세요.
