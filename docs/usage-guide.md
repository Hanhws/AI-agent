# 가닥 사용 가이드 — 켜면 알아서

가닥은 한 번 켜면 이 PC에서 내가 LLM을 어떻게 쓰는지 찾아서, 읽을 수 있는 대화를 읽고, 노선도로 정리해 가닥 창에 보여 줘요.

> 2026-10-04 기준이에요. macOS에서만 확인했어요. **지금 되는 것**: 가닥 앱으로 켜기, Claude Code · Codex 대화 알아서 읽기, 보는 대화부터 정리(본류 · 곁길 · 정함 · 구간 · 요청 나누기), 놓친 일 찾기(빠진 요청 · 요청 외 변경 · 이어 가기)와 판단 기록, 가닥 창(노선도 · 할 일 · 정한 것 · 산출물 · 찾기). 크롬 확장으로 Claude · ChatGPT 웹 대화 읽기(10/4 · 만든 화면으로만 확인, 실제 사이트는 확인 전). **아직 없는 것**: 승인한 종류 자동 실행(10/6), 웹 대화 옆에 붙는 레일 · 노선도(10/8~9), 데스크톱 MCP(10/10). 놓친 일 찾기는 가짜 엔진으로만 시험했고, 실제 Claude 구독 엔진으로는 확인 전이에요.

## 1. 켜기

**가닥은 Mac의 보통 프로그램이에요.** Launchpad나 Spotlight(⌘ 스페이스)에서 ‘가닥’을 찾아 켜요. 창이 하나 뜨고 Dock에 아이콘이 생겨요.

- 끌 때는 창을 닫거나 ⌘Q. 뒤에서 읽고 정리하던 일도 같이 꺼져요.
- Dock에 계속 두려면 켠 뒤 Dock 아이콘을 오른쪽 클릭 → 옵션 → Dock에 유지.
- 창 크기와 자리는 다음에 켤 때도 그대로예요.
- ‘판단 기록’은 창이 하나 더 떠요.

**처음 한 번은 설치해요.** 저장소 폴더의 `가닥 설치.command`를 Finder에서 더블클릭하면, 필요한 것을 내려받고(1분쯤) 가닥 앱을 만들어 응용 프로그램 폴더에 넣은 뒤 켜 줘요.

- 앱을 만들 때 Swift 컴파일러를 써요. 없다고 나오면 터미널에서 `xcode-select --install`로 Xcode 명령어 도구를 깔아요. git을 쓰고 있다면 이미 있어요.
- 앱은 이 저장소 폴더의 코드를 돌려요. 코드를 고치면 앱을 다시 켜기만 하면 돼요. **폴더를 옮기거나 이름을 바꾸면 `가닥 설치.command`를 다시 실행**해요.
- 저장소를 zip으로 받았다면 처음에 macOS가 `가닥 설치.command`를 막을 수 있어요. 오른쪽 클릭 → 열기로 허용하고, 그래도 막히면 시스템 설정 → 개인정보 보호 및 보안에서 ‘그래도 열기’를 눌러요.
- 지우려면 응용 프로그램 폴더의 가닥을 휴지통에 넣어요. 읽어 둔 대화까지 지우려면 `~/.gadak` 폴더도 지워요.

앱 없이 켜거나 macOS가 아니면 저장소 폴더에서 이렇게 해요. 브라우저 창으로 열리고, 끌 때는 화면의 **끄기**나 Ctrl+C예요.

```bash
./.venv/bin/python -m backend.launch
```

켜지면 가닥이 하는 일

1. **찾기** — Claude Code · Codex의 기록 파일, Cursor 설치 여부, 크롬 확장이 연결됐는지를 봐요. 가닥 창의 **찾은 곳**에서 무엇을 찾았는지 볼 수 있어요.
2. **읽기** — 기록 파일의 대화를 `~/.gadak/gadak.db`로 옮겨요. 켜 둔 동안은 2.5초마다 새로 붙은 부분만 읽어서, 지금 하는 대화도 따라와요.
3. **정리** — 화면에 보이는 대화부터 Claude 구독으로 분류해요. 정리 전에는 질문 첫머리가 임시 제목으로 보여요.
4. **놓친 일 찾기** — 정리하다 빠진 것 같은 요청, 요청보다 넓게 바뀐 파일, 같은 프로젝트의 새 대화가 보이면 기록을 다시 읽어 확인하고, 놓친 일이면 할 일에 올려요(2단, 5장).
5. **보여 주기** — 왼쪽에 프로젝트(작업 폴더)와 대화, 위에 노선도, 아래에 그 대화와 레일이 나와요.

## 2. 내가 쓰는 것에 따라

| 내가 쓰는 것 | 가닥이 읽는 방법 | 내가 할 일 | 상태 |
|---|---|---|---|
| Claude Code (VS Code 확장 · 터미널 · 데스크톱 앱의 Code 탭) | 기록 파일을 알아서 읽어요 | 없음 | 됨 |
| Codex (터미널 · VS Code 확장) | 기록 파일을 알아서 읽어요 | 없음 | 됨 (대화 1개로 확인) |
| Cursor | Cursor hook으로 새 대화를 받아요 | 찾은 곳 → **연결** 한 번 | 연결까지 됨 (실제 대화는 확인 전) |
| Claude 웹 · ChatGPT 웹 (크롬) | 크롬 확장이 연 대화를 읽어요 | 크롬에 확장을 **한 번** 넣기 (4-3) | 만든 화면으로만 확인 (실제 사이트는 확인 전) |
| 한 번도 안 연 지난 대화 · 데스크톱 앱의 채팅 | 대화가 서버에 있어요. 내보내기 파일을 넣어요 | 찾은 곳 → **파일 고르기** (4-4) | 만든 파일로만 확인 (실제 내보내기 파일은 확인 전) |
| 유료 LLM이 없음 | 예시 대화 보기 | 주소 끝에 `?demo` | 됨 |

정리에 쓰는 LLM(엔진)은 읽는 곳과 따로예요. 3장을 봐 주세요.

## 3. 엔진 고르기

엔진은 가닥이 대화를 정리할 때 쓰는 LLM이에요. `backend/.env`에서 정해요(`backend/.env.example`을 복사). 기본값 `auto`는 Claude Code가 깔려 있으면 Claude 구독 엔진을, 없으면 ‘엔진 없이’를 골라요.

### 3-1. Claude 구독 엔진 (`claude_cli`) — Pro · Max 구독만 있을 때

내 PC에 로그인돼 있는 Claude Code를 가닥이 대신 불러요. **API 키가 필요 없고 추가 결제도 없어요.**

1. Claude Code를 설치하고 로그인해요. `claude auth status`에 `"subscriptionType": "pro"`처럼 나오면 준비된 거예요.
2. 확인하려면 한 번 불러 봐요.

```bash
./.venv/bin/python -m backend.engines --ping
# {"ok": true, "authMethod": "claude.ai", "subscriptionType": "pro"}
# 응답 {"ok": true} · 2.5초
```

알아 둘 점

- **구독 사용 한도를 같이 써요.** 그래서 지난 대화를 한꺼번에 정리하지 않고, 화면에 보이는 대화와 새로 끝난 턴만 정리해요. 한 번 켠 동안 150번까지만 부르고 멈춰요(`GADAK_MAX_CALLS`로 바꿔요). 놓친 일 찾기(2단)도 같은 한도를 써요.
- **놓친 일 찾기는 확인할 턴 하나에 2~5번 불러요.** 모든 턴이 아니라 정리하다 걸린 턴(빠진 것 같은 요청 · 넓은 변경 · 새 대화)만 봐요. 한 턴에서 부르는 횟수의 한도는 `GADAK_MAX_STEPS`(기본 5), 모델은 `GADAK_CHECK_MODEL`(비우면 정리와 같은 모델)로 바꿔요.
- **턴 6~8개를 한 번에 묻고, 한 번에 10초쯤 걸려요** (10/3 측정: 9턴 대화 하나에 호출 2번 · 15~28초). 50턴짜리 대화는 1분 남짓이에요.
- 환경 변수에 `ANTHROPIC_API_KEY`가 있어도 이 엔진은 구독 로그인으로 불러요.
- 가닥이 부른 Claude Code는 내 설정(hook · MCP · CLAUDE.md)을 싣지 않고, 내 대화 목록에도 남지 않아요.
- **서버에 배포한 가닥에서는 쓸 수 없어요.** 구독 로그인은 내 PC에만 있어요.
- Claude Code 2.1.267에서 확인했어요. 버전이 바뀌면 동작이 달라질 수 있어요.
- 모델은 `GADAK_ENGINE_MODEL`로 바꿔요 (`haiku` · `sonnet` · `opus`, 기본 `haiku`).

### 3-2. API 키 엔진 — 예정

Anthropic API 키로 직접 불러요. 쓴 만큼 과금되고, 배포한 가닥에서도 쓸 수 있어요. 아직 만들지 않았어요.

### 3-3. 엔진 없이 (`none`) — ChatGPT 구독만 있을 때

`GADAK_ENGINE=none`이면 대화를 읽어 보여 주기만 해요. 역 제목은 질문 첫머리 그대로이고, 곁길 · 정함은 나뉘지 않아요.

가닥은 아직 ChatGPT 구독을 엔진으로 쓰지 못해요. ChatGPT를 주로 쓰더라도 Claude 구독이나 API 키가 있으면 그걸 엔진으로 고르면 돼요.

## 4. 읽는 곳별 안내

### 4-1. Claude Code · Codex — 알아서

- 읽는 곳: `~/.claude/projects/` 아래 세션 파일, `~/.codex/sessions/` 아래 세션 파일. **읽기만 하고 두 도구의 설정은 건드리지 않아요.**
- 읽는 것: 내가 친 질문, 답변 글, 바뀐 파일의 전 · 후(Claude Code). 도구 실행 결과와 생각 과정은 옮기지 않아요.
- 프로젝트는 대화를 시작한 작업 폴더의 이름이에요.
- 답이 오기 전에 이어서 보낸 말은 앞 질문에 붙여서 역 하나로 봐요.
- Claude Code에서 대화를 되돌려 고쳐 쓴 경우(rewind), 지워진 쪽 질문도 역으로 보일 수 있어요. ‘숨은 가지’로 묶는 것은 아직 없어요.
- 이 Mac에서 기록 파일 95개(314MB)를 처음 읽는 데 0.5초 걸렸어요.
- 가닥이 알아서 보내게 하려면(5-2) 찾은 곳의 **자동 실행 연결**로 hook 둘만 붙여요. 대화를 읽는 데는 hook이 필요 없어요.
- Claude Code hook(`cursor-hooks/install.py claude`)은 이제 붙이지 않아도 돼요. 기록 파일과 hook을 같이 켜면 같은 턴이 두 번 보일 수 있어요(같은 턴으로 합쳐지는지는 확인 전).

### 4-2. Cursor — 한 번 연결

가닥 창의 **찾은 곳 → 연결**을 누르면 `~/.cursor/hooks.json`과 `~/.cursor/hooks/gadak.sh`가 생기고, 그 뒤로 모든 프로젝트의 Agent 대화를 읽어요.

- 연결한 뒤의 대화부터 읽어요. 연결 전 대화는 아직 읽지 못해요.
- 이미 쓰고 있는 `hooks.json`이 있으면 덮어쓰지 않아요. `python3 cursor-hooks/install.py cursor`가 보여 주는 항목을 직접 합쳐요.
- 한 프로젝트에만 붙이려면 `python3 cursor-hooks/install.py cursor --project /내/프로젝트/폴더`.
- 가닥이 꺼져 있는 동안의 대화는 `~/.gadak/spool.jsonl`에 쌓였다가, 다음에 켤 때 알아서 들어와요.
- 끄려면 `~/.cursor/hooks.json`에서 가닥 항목을 지워요.
- Cursor Cloud Agent에서는 일부 hook이 돌지 않으니 로컬 Agent에서 써요.

Cursor 3.22에서 설치하고, Cursor가 부르는 방식 그대로 실행기를 돌려 보는 데까지 확인했어요. 실제 Agent 대화가 들어오는지는 확인 전이에요.

### 4-3. Claude · ChatGPT 웹 — 크롬 확장 (한 번 넣기)

크롬 확장을 넣어 두면, 크롬에서 연 Claude(claude.ai) · ChatGPT(chatgpt.com) 대화를 읽어 가닥으로 보내요. 대화를 내보낼 필요가 없어요.

**넣는 법** (처음 한 번)

1. 크롬 주소창에 `chrome://extensions`를 넣어요.
2. 오른쪽 위 **개발자 모드**를 켜요.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고, 이 저장소의 `extension` 폴더를 골라요. 가닥 창의 **찾은 곳 → 폴더 경로 복사**를 누른 뒤, 폴더 고르는 창에서 ⌘⇧G를 누르고 붙여 넣으면 빨라요.
4. 이미 열려 있던 Claude · ChatGPT 탭은 한 번 새로고침해요.

**쓰는 법**

- 가닥을 켜 둔 채로 대화를 열거나 이어 가면 돼요. 연 대화가 가닥 창의 목록에 생기고, 새 질문은 몇 초 안에 ‘지금’ 역으로 보여요.
- 지난 대화는 **열면** 읽혀요. 열어 보기만 한 대화는 가닥 창에서 볼 때 정리하고, 지켜보는 동안 새로 끝난 턴은 바로 정리해요.
- 확장 아이콘을 누르면 가닥이 켜져 있는지, 이 탭에서 역을 몇 개 읽었는지 보여요. **이 브라우저에서 대화 읽기**를 끄면 읽지 않아요.
- 가닥이 꺼져 있던 동안의 대화는, 그 탭이 열려 있으면 가닥을 켠 뒤 20초쯤 안에 들어오고, 닫았으면 그 대화를 다시 열 때 들어와요.
- ChatGPT에서 프로젝트 안의 대화는 그 프로젝트 이름으로, Claude도 프로젝트 이름이 보이면 그 이름으로 묶여요. 그 밖에는 ‘(프로젝트 없음)’.
- 내보내기 파일로 먼저 넣은 대화를 열어도 역이 겹치지 않아요.

**읽지 않는 것**: ChatGPT의 임시 채팅, Claude의 시크릿 채팅, 크롬의 시크릿 창, 다른 사이트. 답의 ‘생각 과정’처럼 접혀 있는 부분과 버튼 글도 빼요. 첨부 파일과 만들어진 파일의 이름은 아직 옮기지 않아요.

**알아 둘 것**

- **로그인한 실제 사이트 화면에서는 아직 확인하지 못했어요.** 화면을 읽는 자리(셀렉터)는 아는 대로 적은 것이라, 처음에는 안 읽힐 수 있어요. 확장 아이콘을 눌렀을 때 “대화 글을 찾지 못했어요”가 나오면 **진단 복사**를 눌러 구현 담당에게 보내 주세요. 복사되는 것은 화면의 뼈대(태그 · 클래스 이름)뿐이고 대화 글은 들어 있지 않아요.
- 대화의 날짜는 처음 읽은 날로 보여요(화면에는 메시지의 시각이 없어요). 내보내기 파일로 넣은 대화는 실제 날짜예요.
- Claude 화면에는 메시지마다의 번호가 없어서, 가닥이 질문 글과 차례로 역을 알아봐요. 질문을 고쳐 쓰면 새 역이 생기고 앞의 것도 남아요.
- 확장의 팝업이 “켜져 있는 가닥이 예전 것이에요”라고 하면 가닥을 껐다 켜요. 다시 켤 때 예전 가닥을 끄고 새 코드로 바꿔 켜요.
- 끄려면 `chrome://extensions`에서 가닥을 끄거나 지워요.

### 4-4. 지난 대화 한꺼번에 · 데스크톱 앱의 채팅 — 내보내기 파일

Claude와 ChatGPT의 채팅은 대화가 서버에 있어요. 한 번도 열지 않은 지난 대화를 한꺼번에 넣거나, 크롬을 쓰지 않을 때는 내보내기 파일로 넣어요. 한 번 넣은 뒤로는 크롬 확장(4-3)이 이어서 읽어요.

1. 각 서비스의 설정 → 데이터 내보내기를 신청해요. 메일로 파일이 오는 데 시간이 걸려요.
2. 가닥 창의 **찾은 곳 → 파일 고르기**에서 받은 zip(또는 그 안의 `conversations.json`)을 골라요.
3. ‘(프로젝트 없음)’ 아래에 대화가 들어와요. 같은 파일을 다시 넣어도 겹치지 않아요.

실제 내보내기 파일로는 아직 확인하지 못했어요. 알려진 형식대로 만든 파일로만 시험했으니, 안 읽히면 알려 주세요.

### 4-5. 예정

## 5. 가닥 창 보는 법

- **왼쪽**: 지금 프로젝트의 대화(최근 것이 위), 그 아래 다른 프로젝트. 맨 아래에 상태 한 줄과 찾은 곳 · 끄기.
- **대화 찾기** (왼쪽 위): 찾는 말을 넣으면 프로젝트를 가리지 않고 모든 대화에서 찾아요. 제목 · 프로젝트 이름 · 쓴 곳(ChatGPT · Cursor · Claude Code …)이 맞는 대화가 먼저, 그다음 글이 맞는 대화가 나와요. 누르면 그 대화의 그 자리로 가요. 칸을 비우거나 Esc를 누르면 목록으로 돌아가요.
- **위 노선도 카드**: [이 대화 | 프로젝트 전체]. 검정 테두리 ○ 보통 질문, 빨간 테두리 정함, 빨갛게 채운 점 지금, 회색 곁길, ■ 산출물. 오른쪽 목록에 할 일 · 정한 것 · 산출물과 찾기.
- **아래**: 그 대화(읽기 전용)와 오른쪽 레일. 역을 누르면 그 메시지로 가요. 긴 글은 앞부분만 보이고 ‘전체 보기’로 펼쳐요.
- 밝게 · 어둡게는 시스템 설정을 따라요. 주소 끝에 `?theme=light` · `?theme=dark`로 고정할 수 있어요.

### 5-1. 할 일과 판단 기록 (2단)

- 정리하다 아래 셋이 보이면 가닥이 그 턴의 기록을 다시 읽어 확인해요. 확인하는 동안 왼쪽 아래에 “놓친 일이 있는지 확인하고 있어요”가 떠요.
  - **빠진 요청** — 한 메시지에 요청이 여럿인데 답에서 빠진 것 같을 때. 답변 전체를 보고, 정말 빠졌으면 캡슐 역의 빈 칸과 ‘다시 묻기’가 생겨요.
  - **요청 외 변경** — 파일이 요청보다 넓게 바뀐 것 같을 때. 바뀐 줄과 요청을 맞춰 보고, 요청 밖이면 ‘바뀐 곳 보기 → 원래대로 요청’이 생겨요.
  - **이어 가기** — 같은 프로젝트에 새 대화를 열었을 때(그 프로젝트의 가장 새 대화의 첫 턴). 지난 대화에서 정한 것을 찾아 ‘요약 붙이기’를 만들어요.
- 보는 대화가 먼저이고, 그 안에서는 지금에 가까운 턴부터 봐요. 앞 턴이나 지난 대화까지 볼지는 가닥이 그때그때 정해요.
- 근거를 직접 보지 못한 결론은 할 일로 올리지 않아요.
- 실행 버튼은 글을 클립보드에 담아요. 대화 창에 붙여 넣어 보내요.
- 왼쪽 아래 **판단 기록**을 누르면, 확인한 턴마다 가닥이 어떤 도구를 어떤 순서로 썼고 무엇을 보고 결론 냈는지 나와요(`/trace`). 버린 결론과 그 까닭도 같이 보여요.

### 5-2. 가닥이 알아서 보내기 (자동 실행)

가닥은 보통 글을 복사해 줄 뿐이고, 보내는 것은 내가 해요. **내가 켠 종류만** 가닥이 직접 보내요. 켤 수 있는 종류는 둘이에요.

| 종류 | 가닥이 하는 일 | 언제 |
|---|---|---|
| 요청 외 변경 | “그 부분은 요청하지 않았어. 원래대로 되돌려 줘”를 이어서 보내요 | 턴이 끝났을 때, 가닥이 바뀐 곳을 직접 보고 요청 밖이라고 확인한 경우만 |
| 이어 가기 | 같은 프로젝트의 지난 대화에서 정한 것을 새 대화에 넣어요 | 새 대화가 시작될 때 |

**켜는 법**

1. 가닥 창 오른쪽 **할 일** 목록 맨 아래의 ‘가닥이 알아서 보내는 것’에서 그 종류의 **켜기**를 눌러요. ‘켜짐’으로 바뀌어요.
2. 한마디를 직접 보내는 창에서 **앞으로는 알아서**에 표시해도 같아요.
3. Claude Code라면 한 번만: **찾은 곳 → 자동 실행 연결**. Claude Code 설정(`~/.claude/settings.json`)에 가닥 hook 둘(`Stop` · `SessionStart`)을 더해요. 있던 설정은 그대로 두고, 고치기 전 파일을 `settings.json.gadak-backup`으로 남겨요. 새로 여는 대화부터 돼요.
   Cursor는 ‘연결’을 했으면 따로 할 일이 없어요. 10/4 전에 연결했다면 `~/.cursor/hooks.json`에 `sessionStart` 줄이 없어서 이어 가기 요약은 안 들어가요(요청 외 변경은 돼요).

**어떻게 보이나**

- Claude Code에서는 답이 끝난 뒤 “Stop hook feedback: [가닥이 대신 보냄] …”이 뜨고 이어서 되돌려요. 화면에 ‘Stop hook error’라고 나오는 것은 Claude Code가 이런 이어 가기를 부르는 이름이고, 오류가 아니에요.
- 가닥 창의 할 일 목록에 그 한마디가 ‘가닥이 보냄’으로 남아요.
- 켜 둔 동안에는 **파일이 바뀐 턴**이 끝날 때 가닥의 확인을 기다리느라 최대 40초쯤 더 걸려요. 파일이 안 바뀐 턴과, 켜지 않았을 때는 그대로예요.
- 가닥이 보낸 글 때문에 이어진 턴에는 다시 보내지 않아요.

**끄는 법**: 같은 자리에서 **끄기**. Claude Code의 hook까지 떼려면 찾은 곳 → **자동 실행 끊기**.

Claude Code에서는 실제로 확인했어요. Cursor는 문서대로 만들었지만 실제 Cursor에서는 아직 확인하지 못했어요. 웹(크롬 확장)과 데스크톱 앱에서는 아직 가닥이 직접 보낼 수 없어요.

## 6. 내 대화가 어디로 가나

| 무엇 | 어디에 |
|---|---|
| 대화 원문, 바뀐 파일의 전 · 후 | 내 PC의 `~/.gadak/gadak.db` (저장소 밖) |
| 크롬 확장이 읽은 웹 대화 | 내 PC의 가닥(`127.0.0.1:7311`)으로만 가서 위와 같은 파일에 들어가요. 확장에는 다른 곳으로 보내는 길이 없어요 |
| 가닥이 꺼져 있을 때 Cursor hook이 받은 대화 | `~/.gadak/spool.jsonl`에 쌓였다가 다음에 켤 때 들어감 |
| 정리할 때 그 턴의 질문 앞 500자와 답의 앞뒤 220자씩, 바뀐 파일 이름과 바뀐 줄 수 | 고른 엔진으로 전송. Claude 구독 엔진이면 내 Claude 계정으로 Anthropic에 |

| 사용 기록 (무엇을 눌렀는지, 한마디를 실행했는지, 대화의 턴 수 같은 숫자) | 내 PC의 같은 파일에 쌓여요. **보내기에 동의했을 때만** 가닥 팀 서버로 가요 (6-1) |
| 옮기지 않는 것 | Cursor가 hook에 넘기는 계정 이메일, 도구 실행 결과, 생각 과정 |

- 가닥은 내 PC(127.0.0.1)에서 온 요청만 받아요.
- 글꼴은 Google Fonts에서 받아요. 대화 내용은 가지 않아요.
- 배포 웹 데모는 미리 분류해 둔 예시만 보여 줘요. 내 대화를 올리는 기능이 없어서 그쪽으로는 아무것도 가지 않아요.
- 기록을 모두 지우려면 가닥을 끄고 `~/.gadak` 폴더를 지워요. 다음에 켜면 기록 파일을 처음부터 다시 읽어요.

### 6-1. 사용 기록 보내기 (고를 수 있어요)

가닥 팀이 가닥을 어떻게 고쳐 나갈지 알려고 모으는 기록이에요. 가닥 팀 서버 주소가 정해진 가닥에서만, 처음 켰을 때 한 번 물어요.

| | |
|---|---|
| 보내는 것 | 켠 방법과 입구별 대화 수, 화면에서 누른 것(범위 · 탭 · 찾기 · 역 누르기 …), 한마디가 보이고 실행되거나 미뤄진 것, 대화의 모양(턴 수 · 곁길 수 · 정한 수 · 요청이 여럿인 턴 수 · 파일이 바뀐 턴 수), 정리에 걸린 시간과 멈춘 까닭 |
| 보내지 않는 것 | 대화 글, 역 제목, 정한 것의 내용, 파일 이름과 경로, 프로젝트 이름, 찾기에 넣은 낱말, 계정 · 이메일 · PC 이름 |
| 누가 보냈는지 | 이 PC의 가닥에 붙는 무작위 번호 하나. 대화는 그 번호와 섞어 되돌릴 수 없게 만든 표시로만 구분해요 |
| 언제 | 동의한 뒤에 적힌 기록만, 5분마다. 동의하기 전의 기록은 PC에만 남아요 |

- **찾은 곳 → 사용 기록 보내기**에서 켜고 끌 수 있어요. ‘보내는 것 보기’를 누르면 서버로 가는 모양 그대로 보여요.
- ‘서버에서 지우기’를 누르면 서버에 있는 내 기록을 지우고 보내기를 꺼요. 다시 켜면 새 번호로 시작해요.
- 무엇을 모을 수 있는지는 `backend/usage_schema.py`에 다 적혀 있어요. 거기 없는 것은 PC에서도 서버에서도 버려요.

가닥 팀(서버를 돌리는 쪽)

```bash
GADAK_SERVER_TOKEN=정한-암호 ./.venv/bin/python -m server.app     # http://127.0.0.1:7321 · 통계는 이 주소를 열고 암호를 넣어요
```

- 가닥이 이 서버로 보내게 하려면 `backend/.env`에 `GADAK_COLLECT_URL=http://127.0.0.1:7321`처럼 적어요. 비워 두면 묻지도 보내지도 않아요.
- 인터넷에 올릴 때는 지워지지 않는 자리의 `GADAK_SERVER_DB`와 통계 암호 `GADAK_SERVER_TOKEN`을 정하고, https 주소를 써요. 10/4에 PythonAnywhere 무료 계정에 올렸어요(웹 앱의 WSGI 파일에서 `server.app.create_app()`을 부르는 방식). 주소와 암호는 저장소에 적지 않고 각자 PC의 `서버-정보.local.md`에 둬요.
- 보내기가 안 되면 찾은 곳의 ‘사용 기록 보내기’에 ‘보내지 못하고 있어요’가 보여요. 기록은 PC에 남아 있다가 다음 차례에 다시 가요.

## 7. 안 될 때

| 증상 | 볼 곳 |
|---|---|
| 앱이 “가닥 폴더를 찾지 못했어요”라고 함 | 저장소 폴더를 옮겼거나 이름을 바꾼 거예요. 그 폴더의 `가닥 설치.command`를 다시 실행해요 |
| 앱이 “가닥을 켜지 못했어요”라고 함 | 창에 같이 나온 글을 봐요. 포트가 겹쳤으면 아래 줄, `No module named flask`면 `가닥 설치.command`를 다시 실행해요 |
| (앱 없이 켰을 때) 가닥 창이 안 열림 | 터미널 창에 나온 주소(`http://127.0.0.1:7311`)를 브라우저에 직접 넣어요 |
| “7311번 포트를 다른 프로그램이 쓰고 있어요” | `backend/.env`에 `GADAK_PORT=7312`처럼 다른 번호를 적어요 |
| 코드를 고쳤는데 새 기능이 안 보임 | 가닥을 다시 켜요. 뒤에서 돌던 예전 가닥이 있으면 끄고 지금 코드로 바꿔 켜요(10/4부터) |
| 대화가 하나도 안 보임 | 찾은 곳에서 기록 파일 수를 봐요. Claude Code를 다른 PC에서만 썼다면 이 PC에는 기록이 없어요 |
| 제목이 질문 첫머리 그대로 | 왼쪽 아래 상태 글을 봐요. 엔진이 없거나(3장), 한도에 걸려 멈췄을 수 있어요. ‘정리 다시’를 눌러요 |
| 할 일이 생기지 않음 | 판단 기록을 봐요. 확인한 턴이 없으면 정리하다 걸린 턴이 없었던 거예요. 확인했는데 비어 있으면 ‘한마디를 만들지 않았어요’와 버린 결론이 보여요 |
| `--ping`이 실패 | `claude auth status`로 로그인 확인, 구독 사용 한도 |
| 웹 대화가 안 들어옴 | 확장 아이콘을 눌러 봐요. “가닥이 꺼져 있어요”면 가닥을 켜고, “예전 것이에요”면 가닥을 껐다 켜고, “대화 글을 찾지 못했어요”면 진단 복사를 보내 주세요. 확장을 넣기 전부터 열려 있던 탭은 새로고침해요 |
| 가닥이 알아서 보내지 않음 | ① 할 일 목록 아래에 ‘가닥이 알아서 보내는 것’이 있는지 ② 찾은 곳에 ‘자동 실행 연결됨’인지(연결한 뒤 새로 연 대화여야 해요) ③ 그 턴에 한마디가 생겼는지 봐요. 가닥이 확인을 40초 안에 못 끝내면 보내지 않고, 한마디는 그대로 남아요 |
| Cursor 대화가 안 들어옴 | Cursor의 Customize → Hooks 탭과 Hooks 출력 채널에서 hook이 돌았는지 봐요 |
| hook을 붙인 뒤 Cursor가 느림 | hook은 가닥을 1.5초까지만 기다려요. 그래도 느리면 hook 항목을 지우고 알려 주세요 |
