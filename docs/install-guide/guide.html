Installing Gadak

From install to first launch on a Mac or Windows. No terminal needed.

Gadak turns long conversations with AIs such as Claude and ChatGPT into a transit map and tells you first about what slipped past. You keep chatting where you always do; Gadak only organises the flow alongside.

1Installing on a MacMac

  1. Double-click the dmg file you got. A window opens. Apple silicon Macs use the arm64 file; Intel Macs use x86_64.
  2. Drag Gadak onto the Applications folder on the right.
  3. Close the window. That’s the whole install.

First launch — the Mac blocks it once

Gadak was made as a class project and has no paid Apple developer signature. So you need to allow it yourself once.

  1. Open Gadak from Applications (or Launchpad).
  2. A window says it can’t be opened. Press Done.
    Don’t press ‘Move to Trash’.
  3. Open System Settings → Privacy & Security and scroll down.
  4. Next to ‘“Gadak” was blocked …’, press Open Anyway.
  5. In the window that asks again, press Open Anyway and confirm with your Mac password or Touch ID.

2Installing on WindowsWindows

Windows 10 or 11 is all you need. Everything Gadak needs is in one installer, so there’s nothing else to install.

  1. Double-click ‘Gadak-0.1.0-windows-x64-setup.exe’.
  2. If a blue “Windows protected your PC” window appears, press More info, then Run anyway. Gadak was made as a class project and has no paid signature, so this check is needed once.
  3. Press Install in the installer. It installs for your account only, so it won’t ask for an administrator password.
  4. With ‘Start Gadak’ ticked, press Finish. The Gadak window opens. From then on, start Gadak from the Start menu or the desktop.

How Windows is different

Gadak windowOpens on its own as an Edge (or, failing that, Chrome) window without an address bar. Closing the window turns Gadak off. To start it again, use Gadak in the Start menu.
Connect AIGadak can’t download Claude Code or Codex for you. If one is already installed and signed in on this PC, just pick it; if not, add an LLM API key (section 3). The key is kept only in Windows Credential Manager on this PC.
Not there yetThe floating button (section 7) · Cursor connection · Gadak sending by itself · the Claude usage gauge. Everything else is the same as on a Mac.
Use without installingUnzip ‘Gadak-0.1.0-windows-x64.zip’ and run Start Gadak.cmd inside it.
Removing itSettings → Apps → Installed apps → Gadak → Uninstall. To delete the chats it read as well, delete the C:\Users\your name\.gadak folder too.
The Windows version first came out in 0.1.0. It hasn’t been tried on many PCs yet. If it doesn’t start or behaves oddly, please send C:\Users\your name\.gadak\gadak.log to the makers.

3Connect AI — one button

Connect the AI Gadak uses to sort your chats. The Connect AI window opens by itself when Gadak starts. Set up just one of the three you have.

What you haveWhat to do
Claude subscription
Pro · Max		Press Connect in the ‘Claude subscription’ row.
ChatGPT subscription
Plus · Pro		Press Connect in the ‘ChatGPT subscription’ row.
LLM API key
Anthropic · OpenAI · Gemini		Paste your key in the ‘LLM API key’ box and press Save. Gadak works out which company the key is from.

When you press ‘Connect’ Mac

  1. Gadak downloads the program it needs. ‘Claude Code’ for Claude, ‘Codex’ for ChatGPT. These are each company’s official releases, about 200 MB, so it takes about a minute. Skipped if already there.
  2. Your browser opens. Sign in with your usual account and press Allow. Meanwhile Gadak shows ‘Finish signing in in your browser’.
  3. Back in the Gadak window it says ‘Connected’. Gadak now sorts with that AI.

Windows Gadak can’t download the program for you. Install Claude Code or Codex yourself and sign in, and Gadak finds it; otherwise connect with an LLM API key.

Good to know
· With a subscription there is no extra charge, but Gadak shares the usage limit with your own Claude or ChatGPT use. How much is used shows at the bottom right of the Gadak window (section 5).
· An API key is billed for what it uses. The key is kept only in this Mac’s Keychain (Credential Manager on Windows), and only its last four characters are shown.
· A free Gemini key from Google AI Studio works too. It costs nothing, but the limit is low and what you send may be used by Google to improve its products.
· Gadak never sees your password. You sign in to the company directly in your browser.
· If you connected several, switch with Sort with this in the same window.
· To go without, choose Use without AI. Gadak then only reads and shows your chats.
· If sign-in doesn’t finish within 5 minutes it stops by itself. Just press Connect again.

4Reading chats

Gadak finds and reads the AI chats on this computer. What you need to do depends on where you chat. What it’s reading now is shown under Sources at the bottom left.

Where you use AIWhat to do
Claude Code · CodexNothing. Turn Gadak on and it reads them by itself, following the chat in progress too.
Cursor MacPress Sources → Connect once. It reads from the next chat on.
Claude · ChatGPT on the web
(Chrome)		Add the Gadak extension to Chrome once, following the steps below.
Past chats in bulkAdd the file you got from Settings → Export data in each service with Sources → Choose file. With an AI connected, Gadak groups them by project.

Adding the Chrome extension (once · 2 min)

  1. Under Sources at the bottom left of the Gadak window, press Copy folder path.
  2. Type chrome://extensions in Chrome’s address bar and turn on Developer mode at the top right.
  3. Press Load unpacked. In the folder picker press ⌘ ⇧ G, paste and open. WindowsPaste it into the address box of the folder picker.
  4. Reload any Claude or ChatGPT tabs that were already open.
The extension sends the chats you open in Chrome only to Gadak on this computer. It doesn’t read incognito windows or temporary chats. It isn’t on the Chrome Web Store, which is why Developer mode is needed.
Connect auto-run Mac The button in the Claude Code row under ‘Sources’. It adds Gadak to the Claude Code settings so Gadak can send the two kinds you turned on (undoing unrequested changes · carry-on summary) itself. Reading works the same without it.

5The Gadak window

1 2 3 4 5 6 7 8 9
  • 1Chat list. Grouped by project. Search in the box above; hover over a chat you don’t need and press × to remove it. Press ‹ to fold the list.
  • 2Strip map. One chat is one line. Each dot is one question (a station); click it to go there. Fold and unfold with Esc.
  • 3Chat text. Read only. You keep chatting where you always do.
  • 4Lists. To do · Decided · Files · Ahead. Press a to-do’s button to copy text to send to the AI. Remove a to-do you don’t need with ×.
  • 5Note. The card that pops up when a new to-do appears. Do it now or put it off with ‘Later’.
  • 6Status and buttons. One line on what Gadak is doing now. Below it: Connect AI · Sources · Decision trace · Help · Quit.
  • 7System map. Draws every project and chat on one sheet (section 6).
  • 8Day · Night. Switches between a light and a dark screen. The Mac app also has a Gadak button switch to its left that shows or hides the floating button.
  • 9Usage limit. With a subscription, shows how much of the 5-hour and weekly limits is used. Only shown when it can be read.

The four lists

To doMissed work Gadak found (missed request · unrequested change · unfinished side trip) and suggestions (carry on · repeated question · topic change · next step).
DecidedEverything decided so far, newest first. Click one to go to where it was decided.
FilesFiles that came out of the chat. A file changed several times is grouped into versions (v1 · v2).
AheadPress Look ahead and Gadak finds up to three ways this chat could go. It takes 30 seconds to 2 minutes and uses a little of your AI usage limit.

6Reading the map · system map

One chat is one line. The left is the start, the right is now. Station names are Gadak’s short version of each question.

Main lineA thick line in the project’s colour. The same colour on the system map.
StationA small black dot. One question and its answer. Click it to go there.
DecidedA large black dot with a bold station name. Something was decided there.
NowA red dot with a glow. Where the chat is now.
Side tripA grey line dropping below. A question that wandered off for a while.
To doA red ring below a station is still to do; a grey ring is done. Hover to see it.
FileA small dot with a file name. A file was made or changed there.
SectionThe label above the line: a stage of the conversation. Past sections fold into ticks; click the label to unfold.
TransferThe black arrow at the end of the line. Copies a summary of this chat to paste at the start of a new one.

Use This chat · Whole project on the strip map card to see one chat or the project’s chats joined up. The other marks and words are in Help in the Gadak window → ‘Reading the map’ · ‘Glossary’.

System map — every chat on one sheet

How to read itEach row is a project; each thick segment is a chat. Dates run from left to right. A vertical black line marks where one chat carried on into another (a transfer).
PeriodChoose the last 7 · 15 · 30 days. Zoom with − · Fit · + at the bottom right.
Strip mapClick a line to unfold that chat’s map as a single strip.
View as posterDraws the same map like a transit poster. Close the system map with Esc.

7Floating button — watch while you use other appsMac

When Gadak is on, the Gadak button rests half over the edge of the screen. It stays visible while you use other apps, so you can see the map without going to the Gadak window. Not on Windows yet.

Gadak (centre)Shows or hides the strip map window. Drag it to move it to another edge.
MapShows the strip map of the chat you’re in at the top of the screen.
To do · Decided · FilesOpens a separate list window on that tab.
Search · WindowOpens the Gadak window. Search goes straight to the chat search box.
Red numberHow many to-dos are open in the current chat.

Close floating windows with Esc. While the button is showing, closing the Gadak window doesn’t turn Gadak off. To quit, press ⌘ Q.

Hide · show again. Right-click the Gadak button → Hide Button. Four ways to show it again: the Gadak button switch at the top right of the Gadak window, ⇧ ⌘ B, the menu View → Floating Button, or right-click the Gadak icon in the Dock → Show Floating Button.

Your own buttons — Edit Buttons

Right-click the Gadak button → Edit Buttons to open a small window. Changes save right away and reach the button within a few seconds.

RemovePress Remove on a button you don’t use.
AddPress a dotted one below, such as + Ahead or + Help. Up to six.
ReorderMove with ↑ ↓.
Project buttonsPress + project name to make a button for that project. It opens that project’s strip map without opening the Gadak window. The name on the button can be up to four characters.
Reset to defaultBack to the six (Map · To do · Decided · Files · Search · Window).

When you’re stuck

It won’t open the first timeOn a Mac, check you did ‘Open Anyway’ from section 1; Gadak must be in Applications. On Windows, ‘More info → Run anyway’ from section 2.
Station names are just the start of my questionsNo AI is connected. Connect one under Connect AI at the bottom left.
‘Connect’ never finishesCheck that you finished signing in in your browser. It stops by itself after 5 minutes; just press it again.
It says in red that it stoppedYou hit the AI usage limit or were signed out. Once the limit resets, press Resume sorting.
I don’t see any chatsCheck Sources. If you have never used an AI on this computer, there is nothing to read.
I can’t see the floating button MacIt’s hidden. Turn on the Gadak button switch at the top right of the Gadak window. If it still isn’t there, check all four edges of the screen.
Clicking Gadak doesn’t open a window WindowsThe reason is written in C:\Users\your name\.gadak\gadak.log. If the installer stops saying “Gadak is running”, close the Gadak window and try again.
Where do my chats go?
Chat text is stored only on this computer. Only while sorting does part of a chat go to the AI you connected (your own account). Chat text never goes to the Gadak team’s server.
Removing Gadak
Mac: move Gadak from Applications to the Trash. To delete the chats it read as well, press ⌘ ⇧ G in Finder and delete the ~/.gadak folder too.
Windows: uninstall Gadak under Settings → Apps → Installed apps, and delete the C:\Users\your name\.gadak folder too.
