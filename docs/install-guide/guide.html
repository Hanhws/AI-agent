가닥 설치 안내

Mac에 넣고 처음 켜기까지. 터미널은 열지 않아요.

가닥은 Claude · ChatGPT 같은 AI와 나눈 긴 대화를 지하철 노선도로 정리해 주고, 놓친 일을 먼저 알려 주는 Mac 앱이에요. 대화는 쓰던 곳에서 그대로 하고, 가닥은 옆에서 흐름만 정리해요.

2처음 열기 — Mac이 한 번 막아요

가닥은 학교 과제로 만든 앱이라 Apple의 유료 개발자 서명이 없어요. 그래서 처음 한 번만 직접 허용해 줘야 해요.

  1. 응용 프로그램 폴더(또는 Launchpad)에서 가닥을 열어요.
  2. 열 수 없다는 창이 떠요. 완료를 눌러요.
    ‘휴지통으로 이동’은 누르지 마세요.
  3. 시스템 설정 → 개인정보 보호 및 보안을 열고 아래로 내려요.
  4. ‘가닥이(가) … 차단되었습니다’ 옆의 그래도 열기를 눌러요.
  5. 한 번 더 묻는 창에서 그래도 열기를 누르고, Mac 암호나 Touch ID로 확인해요.
‘가닥’을(를) 열 수 없습니다

Apple은 ‘가닥’에 Mac을 손상시키거나 개인정보를 침해할 수 있는 악성 코드가 없음을 확인할 수 없습니다.

3AI 연결 — 버튼 한 번

가닥이 대화를 정리할 때 쓸 AI를 연결해요. 가닥이 켜지면 AI 연결 창이 저절로 떠요. 셋 가운데 가진 것 하나만 하면 돼요.

가진 것할 일
Claude 구독
Pro · Max		‘Claude 구독’ 칸의 연결하기를 눌러요.
ChatGPT 구독
Plus · Pro		‘ChatGPT 구독’ 칸의 연결하기를 눌러요.
API 키
Anthropic		키(sk-ant-…)를 칸에 붙여 넣고 저장을 눌러요.

‘연결하기’를 누르면

  1. 필요한 프로그램을 가닥이 받아요. Claude는 ‘Claude Code’, ChatGPT는 ‘Codex’예요. 각 회사의 공식 배포 파일이고 200MB쯤이라 1분쯤 걸려요. 이미 있으면 건너뛰어요.
  2. 브라우저가 열려요. 평소 쓰는 계정으로 로그인하고 허용을 눌러요. 그동안 가닥에는 ‘브라우저에서 로그인을 마쳐 주세요’라고 떠 있어요.
  3. 가닥 창으로 돌아오면 ‘연결됨’으로 바뀌어 있어요. 이제 그 AI로 정리해요.
알아 둘 것
· 구독으로 연결하면 추가 요금이 없어요. 대신 평소 쓰는 Claude · ChatGPT와 사용 한도를 같이 써요.
· API 키는 쓴 만큼 요금이 나가요. 키는 이 Mac의 키체인에만 두고, 화면에는 끝 네 글자만 보여요.
· 가닥은 내 암호를 보지 않아요. 로그인은 브라우저에서 그 회사에 직접 해요.
· 여러 개를 연결했으면 같은 창의 이걸로 정리하기로 바꿔요.
· 연결하지 않고 쓰려면 AI 없이 쓰기. 대화를 읽어 보여 주기만 해요.
· 로그인이 5분 안에 끝나지 않으면 저절로 멈춰요. 연결하기를 다시 누르면 돼요.

4대화 읽어 오기

가닥은 이 Mac에서 한 AI 대화를 찾아 읽어요. 어디에서 쓰느냐에 따라 할 일이 달라요. 지금 무엇을 읽고 있는지는 왼쪽 아래 찾은 곳에 나와요.

AI를 쓰는 곳할 일
Claude Code · Codex없어요. 켜면 알아서 읽고, 하는 중인 대화도 따라와요.
Cursor찾은 곳 → 연결을 한 번 눌러요. 그 뒤의 대화부터 읽어요.
Claude · ChatGPT 웹
(크롬)		크롬에 가닥 확장을 한 번 넣어요. 아래 순서대로요.
지난 대화 한꺼번에각 서비스의 설정 → 데이터 내보내기로 받은 파일을 찾은 곳 → 파일 고르기로 넣어요.

크롬 확장 넣기 (한 번 · 2분)

  1. 가닥 창 왼쪽 아래 찾은 곳에서 폴더 경로 복사를 눌러요.
  2. 크롬 주소창에 chrome://extensions를 넣고, 오른쪽 위 개발자 모드를 켜요.
  3. 압축해제된 확장 프로그램을 로드합니다를 눌러요. 폴더 고르는 창에서 ⌘ ⇧ G를 누르고 붙여 넣은 뒤 열어요.
  4. 열려 있던 Claude · ChatGPT 탭은 한 번 새로고침해요.
확장은 크롬에서 연 대화를 이 Mac의 가닥으로만 보내요. 시크릿 창과 임시 채팅은 읽지 않아요. 크롬 웹 스토어에 올린 확장이 아니라서 개발자 모드가 필요해요.

5가닥 창 보는 법

1 2 3 4 5 6
  • 1대화 목록. 프로젝트별로 묶여 있어요. 위의 칸에서 찾고, 필요 없는 대화는 마우스를 올려 ×로 빼요.
  • 2노선도. 대화 한 개가 노선 한 줄이에요. 점 하나가 질문 하나(역)이고, 누르면 그 자리로 가요.
  • 3대화 글. 읽기만 해요. 대화는 쓰던 곳에서 그대로 해요.
  • 4목록 네 칸. 할 일 · 정한 것 · 산출물 · 앞길. 할 일의 버튼을 누르면 AI에게 보낼 글이 복사돼요.
  • 5한마디. 새 할 일이 생기면 뜨는 카드예요. 바로 하거나 ‘나중에’로 미뤄요.
  • 6상태와 버튼. 가닥이 지금 무엇을 하는지 한 줄로 나와요. AI 연결 · 찾은 곳 · 도움말이 여기에 있어요.

노선도의 표시

큰 점 · 굵은 이름그 자리에서 무언가를 정했어요. 정한 내용은 ‘정한 것’ 칸에 모여요.
빨간 점대화가 지금 와 있는 자리예요.
위로 빠지는 회색 선곁길. 하던 이야기에서 잠깐 벗어난 질문이에요.
길쭉한 역한 번에 여러 가지를 부탁한 자리. 속이 빈 점은 답을 못 받은 부탁이에요.

나머지 표시와 낱말은 가닥 창의 도움말 → ‘노선도 읽기’ · ‘낱말 풀이’에 있어요.

6떠 있는 버튼 — 다른 앱을 쓰면서 보기

가닥을 켜면 화면 가장자리에 가닥 버튼이 반쯤 걸쳐 있어요. 다른 앱을 쓰는 동안에도 보여서, 가닥 창으로 가지 않고 노선도를 볼 수 있어요.

가닥 (가운데)노선도 창을 켜고 꺼요. 끌면 다른 가장자리로 옮겨져요.
노선도지금 쓰는 대화의 노선도를 화면 위쪽에 띄워요.
할 일 · 정함 · 산출물그 칸을 연 목록 창을 따로 띄워요.
찾기 · 창가닥 창을 열어요.
빨간 수지금 대화에 열려 있는 할 일 수예요.

떠 있는 창은 Esc로 닫아요. 버튼을 숨기려면 메뉴 보기 → 떠 있는 버튼.

버튼을 내 마음대로 — 버튼 편집

가닥 버튼을 오른쪽 클릭 → 버튼 편집을 누르면 작은 창이 떠요. 바꾸면 바로 저장되고, 몇 초 안에 버튼에 반영돼요.

빼기안 쓰는 버튼의 빼기를 눌러요.
더하기아래의 + 앞길 · + 도움말처럼 점선으로 된 것을 눌러요. 여섯 개까지 둬요.
차례 바꾸기↑ ↓로 옮겨요.
프로젝트 버튼+ 프로젝트 이름을 누르면 그 프로젝트의 버튼이 생겨요. 누르면 가닥 창을 열지 않고 그 프로젝트의 노선도가 떠요. 버튼에 쓸 이름은 네 글자까지 고쳐요.
처음 모양으로여섯 개(노선도 · 할 일 · 정함 · 산출물 · 찾기 · 창)로 되돌려요.

막힐 때

처음에 안 열려요2번의 ‘그래도 열기’를 했는지 봐요. 가닥이 응용 프로그램 폴더에 있어야 해요.
역 이름이 질문 첫머리 그대로예요AI가 연결되지 않았어요. 왼쪽 아래 AI 연결에서 하나를 연결해요.
‘연결하기’가 끝나지 않아요브라우저에서 로그인을 마쳤는지 봐요. 5분이 지나면 저절로 멈춰요. 다시 누르면 돼요.
빨간 글씨로 멈췄다고 나와요AI 사용 한도에 걸렸거나 로그인이 풀렸어요. 한도가 풀린 뒤 정리 다시를 눌러요.
대화가 하나도 안 보여요찾은 곳을 봐요. 이 Mac에서 AI를 쓴 적이 없으면 읽을 기록이 없어요.
떠 있는 버튼이 안 보여요메뉴 보기 → 떠 있는 버튼에 표시가 있는지 보고, 화면의 네 가장자리를 둘러봐요.
내 대화는 어디로 가나요
대화 글은 이 Mac에만 저장돼요. 정리할 때만 그 대화의 일부가 내가 연결한 AI(내 계정)로 가요. 가닥을 만든 팀의 서버로는 대화 글이 가지 않아요.
지우려면
응용 프로그램 폴더의 가닥을 휴지통에 넣어요. 읽어 둔 대화까지 지우려면 Finder에서 ⌘ ⇧ G를 누르고 ~/.gadak 폴더로 가서 그 폴더도 지워요.
