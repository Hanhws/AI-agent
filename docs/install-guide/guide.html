가닥 설치 안내

Mac과 Windows에 넣고 처음 켜기까지. 터미널은 열지 않아요.

가닥은 Claude · ChatGPT 같은 AI와 나눈 긴 대화를 지하철 노선도로 정리해 주고, 놓친 일을 먼저 알려 주는 앱이에요. 대화는 쓰던 곳에서 그대로 하고, 가닥은 옆에서 흐름만 정리해요.

정리할 AI는 하나만 있으면 돼요. Claude 구독(Pro · Max) · ChatGPT 구독(Plus · Pro) · LLM API 키(Anthropic · OpenAI · Gemini) 가운데 하나. 없어도 가닥은 켜져요. 그때는 대화를 읽어 보여 주기만 하고, 역 이름이 질문 첫머리 그대로예요.

  1. 받은 ‘가닥-0.1.0-windows-x64-설치.exe’를 두 번 눌러요.

3AI 연결 — 버튼 한 번

가닥이 대화를 정리할 때 쓸 AI를 연결해요. 가닥이 켜지면 AI 연결 창이 저절로 떠요. 셋 가운데 가진 것 하나만 하면 돼요.

가진 것할 일
Claude 구독
Pro · Max		‘Claude 구독’ 칸의 연결하기를 눌러요.
ChatGPT 구독
Plus · Pro		‘ChatGPT 구독’ 칸의 연결하기를 눌러요.
LLM API 키
Anthropic · OpenAI · Gemini		가진 키를 ‘LLM API 키’ 칸에 붙여 넣고 저장을 눌러요. 어느 회사 키인지는 가닥이 알아봐요.

‘연결하기’를 누르면 Mac

  1. 필요한 프로그램을 가닥이 받아요. Claude는 ‘Claude Code’, ChatGPT는 ‘Codex’예요. 각 회사의 공식 배포 파일이고 200MB쯤이라 1분쯤 걸려요. 이미 있으면 건너뛰어요.
  2. 브라우저가 열려요. 평소 쓰는 계정으로 로그인하고 허용을 눌러요. 그동안 가닥에는 ‘브라우저에서 로그인을 마쳐 주세요’라고 떠 있어요.
  3. 가닥 창으로 돌아오면 ‘연결됨’으로 바뀌어 있어요. 이제 그 AI로 정리해요.

Windows 가닥이 프로그램을 대신 받아 주지 못해요. Claude Code나 Codex를 직접 깔아 로그인해 두면 가닥이 찾아 쓰고, 없으면 LLM API 키로 연결해요.

알아 둘 것
· 구독으로 연결하면 추가 요금이 없어요. 대신 평소 쓰는 Claude · ChatGPT와 사용 한도를 같이 써요. 얼마나 썼는지는 가닥 창 오른쪽 아래에 보여요(5번).
· API 키는 쓴 만큼 요금이 나가요. 키는 이 Mac의 키체인(Windows는 자격 증명 관리자)에만 두고, 화면에는 끝 네 글자만 보여요.
· Google AI Studio의 Gemini 무료 키도 돼요. 요금이 없는 대신 한도가 낮고, 보낸 글이 Google의 제품 개선에 쓰일 수 있어요.
· 가닥은 내 암호를 보지 않아요. 로그인은 브라우저에서 그 회사에 직접 해요.
· 여러 개를 연결했으면 같은 창의 이걸로 정리하기로 바꿔요.
· 연결하지 않고 쓰려면 AI 없이 쓰기. 대화를 읽어 보여 주기만 해요.
· 로그인이 5분 안에 끝나지 않으면 저절로 멈춰요. 연결하기를 다시 누르면 돼요.

4대화 읽어 오기

가닥은 이 컴퓨터에서 한 AI 대화를 찾아 읽어요. 어디에서 쓰느냐에 따라 할 일이 달라요. 지금 무엇을 읽고 있는지는 왼쪽 아래 찾은 곳에 나와요.

AI를 쓰는 곳할 일
Claude Code · Codex없어요. 켜면 알아서 읽고, 하는 중인 대화도 따라와요.
Cursor Mac찾은 곳 → 연결을 한 번 눌러요. 그 뒤의 대화부터 읽어요.
Claude · ChatGPT 웹
(크롬)		크롬에 가닥 확장을 한 번 넣어요. 아래 순서대로요.
지난 대화 한꺼번에각 서비스의 설정 → 데이터 내보내기로 받은 파일을 찾은 곳 → 파일 고르기로 넣어요. AI가 연결돼 있으면 가닥이 프로젝트별로 묶어요.

크롬 확장 넣기 (한 번 · 2분)

  1. 가닥 창 왼쪽 아래 찾은 곳에서 폴더 경로 복사를 눌러요.
  2. 크롬 주소창에 chrome://extensions를 넣고, 오른쪽 위 개발자 모드를 켜요.
  3. 압축해제된 확장 프로그램을 로드합니다를 눌러요. 폴더 고르는 창에서 ⌘ ⇧ G를 누르고 붙여 넣은 뒤 열어요. Windows폴더 고르는 창의 주소 칸에 붙여 넣어요.
  4. 열려 있던 Claude · ChatGPT 탭은 한 번 새로고침해요.
확장은 크롬에서 연 대화를 이 컴퓨터의 가닥으로만 보내요. 시크릿 창과 임시 채팅은 읽지 않아요. 크롬 웹 스토어에 올린 확장이 아니라서 개발자 모드가 필요해요.
자동 실행 연결 Mac ‘찾은 곳’의 Claude Code 칸에 있는 버튼이에요. 누르면 Claude Code 설정에 가닥을 더해서, 내가 켜 둔 두 가지(요청 외 변경 되돌리기 · 이어 가기 요약)를 가닥이 직접 보낼 수 있게 돼요. 누르지 않아도 읽기는 그대로 돼요.

6노선도 읽기 · 전체 지도

대화 한 개가 노선 한 줄이에요. 왼쪽이 처음, 오른쪽이 지금이에요. 역 이름은 가닥이 그 질문을 줄여 붙인 것이에요.

본선프로젝트 색의 굵은 선. 전체 지도에서도 같은 색이에요.
역작은 검은 점. 한 번 묻고 한 번 답한 것. 누르면 그 자리로 가요.
정함큰 검은 점과 굵은 역 이름. 그 자리에서 무언가를 정했어요.
지금빨간 점과 둘레의 빛. 대화가 와 있는 자리예요.
곁길아래로 내려가는 회색 선. 하던 이야기에서 잠깐 벗어난 질문이에요.
할 일역 아래의 빨간 고리는 아직 안 한 일, 회색 고리는 끝낸 일이에요. 올리면 내용이 보여요.
산출물작은 점과 파일 이름. 그 자리에서 파일이 나오거나 바뀌었어요.
구간노선 위의 이름표. 이야기의 단계예요. 지난 구간은 눈금으로 접히고, 이름표를 누르면 펴져요.
환승하기노선 끝의 검은 화살표. 이 대화의 요약을 복사해요. 새 대화 첫머리에 붙여 넣어요.

노선도 카드의 이 대화 · 프로젝트 전체로 한 대화만 볼지, 같은 프로젝트의 대화를 이어 볼지 골라요. 나머지 표시와 낱말은 가닥 창의 도움말 → ‘노선도 읽기’ · ‘낱말 풀이’에 있어요.

7떠 있는 버튼 — 다른 앱을 쓰면서 보기Mac

가닥 (가운데)노선도 창을 켜고 꺼요. 끌면 다른 가장자리로 옮겨져요.
노선도지금 쓰는 대화의 노선도를 화면 위쪽에 띄워요.

떠 있는 창은 Esc로 닫아요. 버튼이 떠 있는 동안에는 가닥 창을 닫아도 가닥이 꺼지지 않아요. 끄려면 ⌘ Q.

숨기기 · 다시 켜기. 가닥 버튼을 오른쪽 클릭 → 버튼 숨기기. 다시 켜는 길은 넷이에요: 가닥 창 맨 위 오른쪽의 가닥 토글 스위치, ⇧ ⌘ B, 메뉴 보기 → 떠 있는 버튼, Dock의 가닥 아이콘 오른쪽 클릭 → 떠 있는 버튼 보이기.

버튼을 내 마음대로 — 버튼 편집

가닥 버튼을 오른쪽 클릭 → 버튼 편집을 누르면 작은 창이 떠요. 바꾸면 바로 저장되고, 몇 초 안에 버튼에 반영돼요.

빼기안 쓰는 버튼의 빼기를 눌러요.
더하기아래의 + 앞길 · + 도움말처럼 점선으로 된 것을 눌러요. 여섯 개까지 둬요.
차례 바꾸기↑ ↓로 옮겨요.

막힐 때

처음에 안 열려요Mac은 1번의 ‘그래도 열기’를 했는지 봐요. 가닥이 응용 프로그램 폴더에 있어야 해요. Windows는 2번의 ‘추가 정보 → 실행’.
역 이름이 질문 첫머리 그대로예요AI가 연결되지 않았어요. 왼쪽 아래 AI 연결에서 하나를 연결해요.
‘연결하기’가 끝나지 않아요브라우저에서 로그인을 마쳤는지 봐요. 5분이 지나면 저절로 멈춰요. 다시 누르면 돼요.
빨간 글씨로 멈췄다고 나와요AI 사용 한도에 걸렸거나 로그인이 풀렸어요. 한도가 풀린 뒤 정리 다시를 눌러요.
대화가 하나도 안 보여요찾은 곳을 봐요. 이 컴퓨터에서 AI를 쓴 적이 없으면 읽을 기록이 없어요.
떠 있는 버튼이 안 보여요 Mac숨겨 둔 거예요. 가닥 창 맨 위 오른쪽의 가닥 토글을 켜요. 켰는데도 없으면 화면의 네 가장자리를 둘러봐요.
가닥을 눌러도 창이 안 떠요 WindowsC:\Users\내 이름\.gadak\gadak.log에 까닭이 적혀 있어요. 설치가 “가닥이 켜져 있어요”라며 멈추면 가닥 창을 닫고 다시 해요.
내 대화는 어디로 가나요
대화 글은 이 컴퓨터에만 저장돼요. 정리할 때만 그 대화의 일부가 내가 연결한 AI(내 계정)로 가요. 가닥을 만든 팀의 서버로는 대화 글이 가지 않아요.
지우려면
Mac: 응용 프로그램 폴더의 가닥을 휴지통에 넣어요. 읽어 둔 대화까지 지우려면 Finder에서 ⌘ ⇧ G를 누르고 ~/.gadak 폴더도 지워요.
Windows: 설정 → 앱 → 설치된 앱에서 가닥을 제거하고, C:\Users\내 이름\.gadak 폴더도 지워요.
