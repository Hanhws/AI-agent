어느 쪽인지 모르겠다면 화면 왼쪽 위 사과 메뉴 → 이 Mac에 관하여를 열어요. ‘칩’ 줄에 Apple M…이 보이면 Apple Silicon, ‘프로세서’ 줄에 Intel이 보이면 Intel이에요.

Mac에서 처음 여는 법

  1. 받은 디스크 이미지(.dmg)를 열고, 가닥을 옆의 응용 프로그램 폴더로 끌어 넣어요.
  2. 응용 프로그램 폴더에서 가닥을 열어요. 처음 한 번은 macOS가 “확인되지 않은 개발자”라며 막아요. ‘완료’를 눌러 닫아요.
  3. 시스템 설정 → 개인정보 보호 및 보안으로 가서 아래쪽의 그래도 열기를 눌러요. macOS 14 이하에서는 가닥을 오른쪽 클릭 → 열기 → 열기로도 돼요.
  4. 가닥이 켜지면 AI 연결 창에서 쓸 AI를 하나 골라요. 다음부터는 그냥 열려요.

꼭 응용 프로그램 폴더로 옮긴 뒤에 켜 주세요. 디스크 이미지 안에서 바로 켜면 Cursor · Claude Code 연결이 안 돼요.

Windows에서 처음 여는 법

  1. 받은 설치 파일(.exe)을 열어요. “Windows의 PC 보호”라는 파란 창이 뜨면 추가 정보 → 실행을 눌러요.
  2. ‘다음’ → ‘설치’. 내 계정에만 깔려서 관리자 암호는 필요 없어요. 파이썬도 같이 깔려요.
  3. 시작 메뉴나 바탕 화면의 가닥을 눌러 켜요. Edge나 Chrome의 주소창 없는 창으로 떠요. 그 창을 닫으면 가닥도 꺼져요.
  4. 왼쪽 아래 AI 연결에서 하나를 골라요. Claude Code나 Codex가 깔려 있으면 그대로 쓰고, 없으면 LLM API 키를 붙여 넣어요.

받은 파일 확인하기 (SHA-256)

왜 경고가 뜨나요? 가닥은 과제로 만든 앱이라 Apple(연 99달러)과 Microsoft의 유료 서명이 없어요. 경고는 서명이 없다는 뜻이고, 파일이 맞는지는 아래 확인 값으로 볼 수 있어요.

받은 파일의 확인 값이 아래와 한 글자도 다르지 않으면 같은 파일이에요.

크롬 확장웹의 Claude · ChatGPT 대화 읽기

확장을 넣어 두면 크롬에서 연 claude.ai · chatgpt.com 대화를 읽어 내 PC의 가닥으로만 보내요. 웹스토어에 올리지 않아서 개발자 모드로 넣어요.

확장 zip 받기
  1. 받은 zip을 풀어요. 가닥 앱을 이미 깔았다면 풀지 않아도 돼요. 가닥 창의 찾은 곳 → 폴더 경로 복사로 앱 안의 확장 폴더를 쓸 수 있어요.
  2. 크롬 주소창에 chrome://extensions를 넣고, 오른쪽 위 개발자 모드를 켜요.
  3. 압축해제된 확장 프로그램을 로드합니다를 누르고 푼 폴더(gadak-extension)를 골라요.
  4. 이미 열려 있던 Claude · ChatGPT 탭은 한 번 새로고침해요. 가닥을 켜 둔 채로 대화를 열면 목록에 생겨요.

Claude 웹은 읽는 것을 확인했고, ChatGPT 웹은 아직 확인하지 못했어요. 임시 채팅과 시크릿 창은 읽지 않아요.
